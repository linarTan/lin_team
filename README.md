# Тихие вещи

Одностраничный учебный магазин для рабочего стола. 18 товаров с локальными фотографиями Pexels. Оплаты, регистрации, доставки и отправки заказов нет; ассортимент, история и цены демонстрационные.

## Запуск

Python 3.12+; зависимости не требуются. Из корня проекта:

```bash
python3 main.py
```

Откройте http://localhost:8000. Сервер должен оставаться запущенным. Остановка — Control+C. Другой порт: `PORT=8001 python3 main.py`.

## Возможности

- Каталог, поиск без учёта регистра и е/ё, категории, сортировка, сброс фильтров.
- Избранное, три готовых набора, случайная находка без непосредственного повтора.
- Корзина: повторное добавление, количество, цена строки, итог, удаление и отмена последнего удаления. При количестве 1 кнопка «−» удаляет товар; отдельная кнопка «Удалить» сохранена.
- Корзина и избранное очищаются при перезагрузке. Наборы добавляют по одному экземпляру трёх товаров, без скидки.
- История магазина, раскрывающиеся характеристики и FAQ.
- Тёплые цветные подборки, адаптивная сетка, постоянная ссылка на корзину на телефоне.
- Клавиатурное управление, видимый фокус, aria-live, reduced-motion, заглушка фото.

Цены первых товаров сохранены: блокнот 100 ₽, кружка 200 ₽, стикеры 50 ₽. По одному экземпляру всех 18 товаров — 7 320 ₽.

## Файлы

`site/index.html` — страница; `site/styles.css` — оформление; `site/app.js` — каталог, состояние и действия; `site/assets/` — фотографии и страница источников. Существующий `main.py` сохранён без изменений. Фотографии доступны локально, оригиналы и лицензия указаны в `site/assets/photo-credits.html`.

## Проверка

```bash
python3 tests/smoke.py
python3 -m unittest discover -s tests
```

Подробный отчёт о браузерных проверках, исправлениях и ограничениях — в QA.md.

Основной сценарий: 0 ₽ → блокнот 100 ₽ → кружка 300 ₽ → ещё блокнот 400 ₽ → уменьшить блокноты 300 ₽ → удалить кружку 100 ₽ → минус у блокнота 0 ₽ → отмена 100 ₽.

## Архив

```bash
python3 main.py --pack
```

`shop.zip` содержит готовый статический сайт с index.html в корне. Распакуйте в пустую папку, запустите `python3 -m http.server 8002`, откройте http://localhost:8002. В архив не входят Python-сервер и документация проекта. Для переноса исходников скопируйте site/, README.md и QA.md, сохранив main.py целевого проекта.
